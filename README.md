# STM32-FOC-HALL ： Hall-Sensor-Based-Three-Loop-PID-FOC-Motor-Controller STM32-FOC-HALL  
# 基于霍尔传感器的三环PID控制系统
基于 STM32F407 的 20kHz 电流环 / 1kHz 速度环 / 200Hz 位置环 三轴串级 FOC 实现，仅用 三路霍尔传感器 完成 50–3500 rpm 全区间速度闭环（±1.5%），内置 18 项补偿机制（摩擦前馈 / 死区补偿 / 角度助推 / PLL 观测器 / 抗积分饱和等），支持 VOFA+ 在线调参与实时遥测

### 1.2 调试方法论亮点（简历加分项）



* **取证级调试**：同一串口流内同时解析固件转速反馈和固件输出电角度，用净转数法独立验证反馈标度，定位了 "反馈链 5× 增益误差" 的误判（实际是低速锁死 bug）

* **二进制帧相位锁定**：自定义 JustFloat 协议解析器，通过连续帧尾匹配实现相位锁定，支持丢帧重同步

* **安全采集脚本**：实时监控转速 / 电流，超限自动发停机命令，硬件调试零风险

## 3. 软件架构

### 3.1 三环串级控制架构



```
位置指令(°) → [位置环 200Hz] → 速度指令(rpm) → [速度环 1kHz] → Iq指令(A)
                                                                          ↓
三相电流 ← [SVPWM] ← [死区补偿] ← [电流环 20kHz] ← Clarke/Park ← ADC采样
                ↑                                              ↑
           TIM8 20kHz                                    电角度观测
          (PWM+ADC触发)                              (霍尔+PLL+助推)
```

### 3.2 控制节拍



| 环       | 频率     | 实现方式                          | 周期    |
| ------- | ------ | ----------------------------- | ----- |
| 电流环     | 20 kHz | ADC 注入组 JEOC 中断（TIM8\_CC4 触发） | 50µs  |
| 速度环     | 1 kHz  | 电流环内分频（SPEED\_LOOP\_DIV=20）   | 1ms   |
| 位置环     | 200 Hz | 电流环内分频（POS\_LOOP\_DIV=100）    | 5ms   |
| VOFA 遥测 | 可变     | 主循环 / 状态机内调用                  | 取决于帧长 |

### 3.3 上电状态机



```
ALIGN(0°定位, 1s, Id=0.5A)
  → ALIGN2(180°定位, 1s, Id=0.5A)
    → CALIB(零位细分标定, 缓慢拖动跨霍尔边沿)
      → DIRCHK(转矩方向自检, Iq=0.25A探测极性)
        → RUN(三模式可在线切换: m0转矩/m1速度/m2位置)
```

## 4. 核心补偿机制详解（项目最核心亮点）

> **这一节是开源项目的灵魂，也是简历的技术深度体现。**
> 每一项都用 "物理问题→数学 / 工程方案→代码位置→实测效果" 四段式写。

### 4.1 电流环补偿（4 项）

#### 4.1.1 死区电压补偿



* **物理问题**：逆变器上下管死区时间 Tdt=357ns，造成每相平均电压损失 ≈ (Tdt/Ts)・Udc = (357ns/50µs)×24V ≈ 0.171V。而静止维持 0.3A 只需 I・R=0.125V—— 不补偿的话，低 Iq 指令本身就是 "糊" 的。

* **方案**：按三相电流符号投影到 dq 轴，叠加到 Vd/Vq；|i|<0.05A 时线性过渡避免零电流抖动。

* **代码**：`Deadtime_Compensate()` in `Users/Src/StateMachine.c`，调用点在 Park 之后、SVPWM 之前。

* **参数**：`DEAD_TIME_V=0.171V`, `DEAD_IZERO_A=0.05A`, `DEADTIME_COMP_SIGN=1.0`

* **效果**：0.19A 小电流下 Iq 跟踪偏差 < 0.003A，低速力矩充足。

#### 4.1.2 电流采样滤波整定



* **问题**：三级串联一阶低通，原系数 0.2 对应极点≈710Hz，在 300Hz 电流环带宽上吃掉约 69° 相位，相位裕度只剩十几度。

* **方案**：系数改为 0.4，极点≈1.6kHz，相位损失减半。

* **参数**：`CURR_FILTER_ALPHA=0.40`

#### 4.1.3 零极点对消法整定



* **问题**：手动整定 PI 参数困难，且难以保证相位裕度。

* **方案**：用电机实际 R/L 直接计算：Kp = L・ωc・2π, Ki = R・ωc・2π，带宽 300Hz。

* **参数**：MOTOR\_R=0.415Ω, MOTOR\_L=1.24mH → Kp=2.34, Ki=782.3

* **效果**：电流环跟踪偏差 < 0.005A。

#### 4.1.4 输出限幅 / 抗积分饱和



* **参数**：`CURRENT_OUT_MAX = Udc/√3 = 13.856V`

### 4.2 速度环补偿（9 项）—— 本项目最核心

#### 4.2.1 ⭐ 摩擦前馈状态机（最亮点）



* **物理问题**：静摩擦门槛约 0.15–0.40A，开环实测 0.10–0.16A 全部 "粘住→突跳"。传统 PI 在低速时要么力矩不足（粘住），要么积分饱和（突跳过冲→刹回→振荡）。

* **方案**：四状态前馈状态机：


  * `REST`（静止）：目标非零立即给`START_A=0.50A`破障，150ms 内爬升到`STATIC_A=0.75A`

  * `MOVING`（转动）：前馈降至`KINETIC_A=0.15A`维持转动

  * 刚脱开时保留`RELEASE_A=0.35A`，80ms 平滑降至动摩擦电流，防止转矩突降导致再次停转

  * `BRAKE`（超速）：关闭补偿，自然摩擦减速

* **代码**：`PID_FrictionFeedforward()` in `Algorithm/Src/PID.c`

* **参数**：`SPEED_FRICTION_STATIC_A=0.75`, `KINETIC_A=0.15`, `RELEASE_A=0.35`, `START_A=0.50`

* **效果**：50rpm 稳态 Iq 从修复前的 0.79A（低速钳制用满）降至 0.19A，无过冲振荡。

#### 4.2.2 ⭐ 角度助推（I/F 蠕动）—— 解决低速锁死



* **物理问题**：霍尔在零速 / 极低速下给不出转子在 60° 扇区内的细分位置。丢边沿后若估算角停止推进，电流矢量静止在定子上，转子永磁 d 轴被吸到 Δ=0，转矩 = Kt・Iq・cos (Δ)→0，转子不动又永远没有新边沿→**永久自锁**。

* **方案**：命令了电流且转速很低时，让电角度按 10rad/s（≈24rpm 机械）的 "蠕动速度" 继续旋转（开环 I/F 硬拖），转子跟着转过 15° 机械角就产生新边沿，随即交回霍尔闭环。

* **迟滞**：低于 25rpm 进入助推，高于 45rpm 退出（防止边界振荡）

* **代码**：`AngleAssist_Creep()` in `Users/Src/StateMachine.c`

* **效果**：50rpm 从完全锁死 (0rpm)→49–50rpm 稳定运行；100rpm 从反复停转→97–101rpm。

#### 4.2.3 丢边沿衰减处理



* **问题**：旧代码丢边沿后直接清零估算角速度→角度冻结→自锁。

* **方案**：分两支：有助推请求时按 ±W\_CREEP 推进；无请求时按 60rad/s² 线性衰减到 0（不直接清零），且助推期故意不夹 60° 扇区，让估算角开环越过边界。

* **代码**：`BSP/Src/bsp_encoder.c:931-961`

#### 4.2.4 转矩抬底



* **问题**：小目标下速度环 PI 输出不足以起转。

* **方案**：堵转且目标 | iq|\<FLOOR 时实际电流抬到 0.50A（> 静摩擦临界 0.40A），转子启动 (>30rpm) 后回到用户目标。

* **参数**：`CURR_BOOST_FLOOR_A=0.50`, 迟滞 10/30rpm

#### 4.2.5 ⭐ PLL 转速观测器



* **问题**：霍尔单边沿 T 法测速有 60° 量化台阶 + 10ms 窗口延迟，速度环对台阶过激响应导致 Iq 猛冲→力矩冲击→自激振荡。

* **方案**：二阶 PLL 跟踪连续机械角（霍尔边沿 + 估算内插），输出连续平滑的机械角速度，无采样保持台阶。输出后加 15Hz 低通进一步衰减换相台阶尖峰。

* **代码**：`PLL_Loop()` in `Algorithm/Src/PLL.c`

* **参数**：`kp_theta=300`, `ki_theta=20000`, `SPEED_PLL_LP_HZ=15Hz`

* **效果**：反馈与真值一致到 0.4–2.4%，无量化噪声。

#### 4.2.6 PLL 输出速率钳位



* **问题**：霍尔换相瞬间角度台阶造成转速尖峰。

* **方案**：每帧 ±300rpm 钳位（真实物理上限≈170rpm / 帧）。

#### 4.2.7 低速禁反向制动



* **问题**：低速下反馈抖动导致 PI 发出反向电流，把电机刹停并进入振荡。

* **方案**：200rpm 以下同向运行不输出反向制动 Iq，交给自然摩擦减速。

#### 4.2.8 抗积分饱和（非对称钳制）



* **问题**：小目标时积分无上限瞬间给满 2A。

* **方案**：


  * 对称上限：`SPEED_IQ_MAX/Ki = 2.0/0.01 = 200`

  * 负向钳制：`SPEED_IQ_NEG_LIM_A/Ki = 0.50/0.01 = 50`（刹车后积分最深 - 0.50A，恢复期仍有正向保持力矩）

  * 低速正向钳制：`(0.15 + 0.0008×|target|)/Ki`（仅 | target|≤200rpm）

* **效果**：阶跃响应无明显超调。

#### 4.2.9 Iq 指令斜率限幅



* **参数**：`SPEED_IQ_SLEW_A_S=100A/s`，防止指令跳变引起机械冲击。

### 4.3 位置环补偿（5 项）

#### 4.3.1 破静摩擦启动补偿



* **方案**：位置环指令≥10rpm（误差≥\~2.9°）且转子静止时，Iq 抬底到 0.65A 破障；启动后撤除。

* **参数**：`POS_BOOST_A=0.65`, `POS_BOOST_CMD_RPM=10`, 迟滞 10/30rpm

#### 4.3.2 单圈绝对角 + 最短路径



* **问题**：累计机械角可达几万度，直接与目标 \[0,360°) 相减产生巨大误差→位置环饱和乱推。

* **方案**：反馈用`fmod`归一化到 \[0,2π)，误差走最短路径（±180°）。

#### 4.3.3 位置反馈低通 + 切入重置



* **问题**：ST-LINK 烧录复位不清 SRAM，static 变量残留导致启动猛冲。

* **方案**：切入位置模式时将低通状态和输出 prev 对齐真值。

#### 4.3.4 位置输出斜率限制



* **参数**：`POS_OUT_RATE=2rpm/5ms`，防止目标切换机械冲击。

#### 4.3.5 位置专用助推



* **方案**：位置模式下独立的蠕动速度（3rad/s≈7rpm），防止位置模式丢边沿自锁。

* **注意**：位置模式不使用速度模式的角度助推，有独立通道。

## 7. 快速开始

### 7.1 环境要求



* Keil MDK-ARM 5.x（工程文件在`MDK-ARM/`）

* STM32CubeMX 6.x（可选，用于重新配置引脚）

* VOFA+ 上位机（用于调参和波形观察）

* Python 3.8+（用于数据采集和分析，需`pip install pyserial matplotlib numpy pandas`）

### 7.2 编译烧录



1. 用 Keil 打开`MDK-ARM/Base_Project.uvprojx`

2. 编译（F7）

3. 用 ST-LINK 烧录（F8）

### 7.3 上电运行



1. 上电后电机自动执行：对齐 (0°)→对齐 (180°)→零位标定→方向自检→进入 RUN 状态

2. 默认进入转矩模式 (m0)，Iq=0

3. 打开 VOFA+，选择串口，波特率 921600，协议选 JustFloat

### 7.4 基本操作



```
# 切换到速度模式，给定1000rpm
m1
rpm=1000

# 切换到转矩模式，给定0.3A
m0
iq=0.3

# 切换到位置模式，转到180°
m2
pos=180

# 紧急停机（任何模式下）
iq=0
rpm=0
```

### 7.5 数据采集



```
# 安装依赖
pip install pyserial matplotlib numpy pandas

# 三模式综合采集（带安全保护，自动停机）
python _tools/foc_three_mode_capture.py --mode 0  # 转矩
python _tools/foc_three_mode_capture.py --mode 1  # 速度
python _tools/foc_three_mode_capture.py --mode 2  # 位置

# 生成分析报告和图表
python _tools/foc_analysis_report.py
```

## 8. 已知不足与改进方向（诚实记录，开源项目必备）

> **写不足不丢人，反而体现工程素养。**
>
>  面试官很看重 "你知道自己项目的边界在哪"。



| # | 不足                  | 影响                     | 改进方向                                       |
| - | ------------------- | ---------------------- | ------------------------------------------ |
| 1 | **位置模式回程不到位**       | 反向运动最大误差 - 118.6°      | 检查位置模式反向摩擦补偿方向逻辑；提高 POS\_RPM\_MAX；增加回程专用补偿 |
| 2 | **电流采样固定偏置≈+0.13A** | 小电流指令时 Iq 实测偏高         | 运行期动态零点校准；开启扇区无效相修正                        |
| 3 | **速度帧缺转速通道**        | 速度模式 18 通道中无直接 rpm 反馈  | 在 VOFA.c 速度分支增加 Motor\_GetSpeedFB () 通道    |
| 4 | **位置分辨率下限 7.5°**    | 位置稳态误差 std 5-11°       | 改用编码器 / 磁编码器；或增加观测器插值精度                    |
| 5 | **低速瞬时纹波 ±25%**     | 50rpm 瞬时转速波动大（均值准确）    | 系机械粘滑本性，可尝试更高分辨率反馈或非线性 PID                 |
| 6 | **转矩模式大电流电压饱和**     | ≥0.5A 时转速进入 3300rpm 平台 | 系 24V 母线限制，可弱磁扩速                           |
| 7 | **位置环输出限速 40rpm**   | 大角度阶跃响应慢               | 可提高到 60-80rpm（需重新整定）                       |

## 附录 B：VOFA + 协议帧格式

### JustFloat 协议



* 帧结构：`[float1][float2]...[floatN][0x00][0x00][0x80][0x7f]`

* 帧长 = 通道数 ×4 + 4

* 小端序 float32

### 命令格式（文本，以 \n 结尾）



* 模式切换：`m0`/`m1`/`m2`

* 转矩：`iq=0.3` 或 `q0.3`

* 速度：`rpm=1000` 或 `s1000` 或纯数字`1000`

* 位置：`pos=180` 或 `p180`，`posr=3.14`(rad)

* PID：`ckp=2.34`, `ski=0.01`, `pkp=200`
